Exploratory Data Analysis (EDA) on Titanic Dataset
Project Overview :
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to uncover hidden patterns, relationships, and trends affecting passenger survival.

The analysis includes:
Data cleaning
Statistical summaries
Data visualization
Correlation analysis
Insight generation
Objective

The main objective of this project is to:
Understand dataset structure
Analyze passenger survival trends
Identify important influencing factors
Develop analytical and visualization skills
